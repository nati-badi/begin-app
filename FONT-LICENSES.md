All fonts bundled in `app/src/main/res/font/` are free to use and redistribute.

| Font | License |
|---|---|
| Inter, Poppins, DM Sans, Nunito, Playfair Display, Lora, Manrope, Fraunces, Space Grotesk | SIL Open Font License 1.1 (Google Fonts) |
| Carlito (based on Lato) | SIL Open Font License 1.1 |
| Noto Sans Ethiopic, Noto Serif Ethiopic (regular, light, black), Abyssinica SIL | SIL Open Font License 1.1 |
| Ethiopic Lessan, Ethiopic Sadiss, Ethiopic Abay | SIL Open Font License 1.1 (stated inside the font files) |
| FreeSerif (GNU FreeFont, reduced to Ethiopic and basic Latin) | GNU GPL with the font exception |

Variable fonts (Lora, Manrope, Fraunces, Space Grotesk, Noto Ethiopic) were saved as fixed-weight files (Bold, Light or Black) so they work on every Android version.
